## 🔄 工作流程

### 创建新美术资源的标准流程

#### 步骤1：查阅规范
1. 打开 `ART_STYLE_GUIDE.md`
2. 找到对应的资源类型章节
3. 记录所需的色彩、尺寸、效果参数

#### 步骤2：选择创建方式

**方式A：使用Python脚本（推荐）**
1. 复制 `generate_assets_clean.py`
2. 修改参数（颜色、尺寸、效果）
3. 运行脚本生成资源
4. 优点：快速、一致、可重复

**方式B：使用设计软件**
1. 使用Photoshop/Figma等工具
2. 严格按照规范设置参数
3. 手动绘制资源
4. 优点：灵活、可添加复杂细节

#### 步骤3：质量检查
1. 对照 `ART_STYLE_GUIDE.md` 中的"质量检查清单"
2. 检查色彩、尺寸、效果是否符合规范
3. 在Cocos Creator中测试显示效果

#### 步骤4：导入使用
1. 将资源放入 `downloaded_assets/` 对应目录
2. 在Cocos Creator中刷新资源
3. 应用到游戏场景中
