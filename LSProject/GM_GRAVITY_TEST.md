# GM配置文档 - 重力测试

## 🎮 GM重力测试功能

快速测试4个方向的重力系统。

---

## ⚙️ 配置方式

### 方法1：属性面板配置

1. 选中 `GameCore` 节点
2. 在属性检查器中找到 `Gm Gravity Direction`
3. 设置值：
   - **-1** = 自动（跟随敌人）
   - **0** = 向下 ↓（默认）
   - **1** = 向上 ↑
   - **2** = 向左 ←
   - **3** = 向右 →

### 方法2：运行时快捷键

游戏运行时按数字键切换：
- **1键** = 向下 ↓
- **2键** = 向上 ↑
- **3键** = 向左 ←
- **4键** = 向右 →

---

## 🧪 测试步骤

### 测试向下（默认）
1. 设置 `Gm Gravity Direction = 0`
2. 运行游戏
3. 消除方块
4. 观察：方块从上往下掉落

### 测试向上
1. 设置 `Gm Gravity Direction = 1`
2. 运行游戏
3. 消除方块
4. 观察：方块从下往上掉落

### 测试向左
1. 设置 `Gm Gravity Direction = 2`
2. 运行游戏
3. 消除方块
4. 观察：方块从右往左掉落

### 测试向右
1. 设置 `Gm Gravity Direction = 3`
2. 运行游戏
3. 消除方块
4. 观察：方块从左往右掉落

### 测试运行时切换
1. 设置 `Gm Gravity Direction = -1`（自动）
2. 运行游戏
3. 按 **1/2/3/4** 键切换方向
4. 消除方块观察效果

---

## 📊 控制台输出

切换重力时会显示：
```
[GravitySystem] Gravity changed: ↓ 向下 -> ↑ 向上
[GameCore] GM: Gravity changed to ↑ 向上
```

## 🎯 测试要点

### 向下（默认）
- ✅ 方块从上方生成
- ✅ 向下掉落填充空位
- ✅ 底部先填满

### 向上
- ✅ 方块从下方生成
- ✅ 向上掉落填充空位
- ✅ 顶部先填满

### 向左
- ✅ 方块从右侧生成
- ✅ 向左掉落填充空位
- ✅ 左侧先填满

### 向右
- ✅ 方块从左侧生成
- ✅ 向右掉落填充空位
- ✅ 右侧先填满

---

## 🐛 可能的问题

### 方块不掉落
- 检查是否有石头方块阻挡
- 检查是否有冰冻方块

### 方块位置错误
- 可能是动画问题
- 刷新浏览器重试

### 切换后卡住
- 正常现象，等待动画完成
- 不要在processing时切换

---

## 💡 推荐测试流程

1. **先测试默认向下** - 确保基础功能正常
2. **测试向上** - 最简单的变化
3. **测试向左/右** - 横向掉落
4. **运行时切换** - 测试动态切换
5. **连续消除** - 测试连锁反应

---

## 🎮 重力敌人测试

要测试重力敌人自动切换：
1. 设置 `Gm Start Stage = 41`（重力敌人关卡）
2. 设置 `Gm Gravity Direction = -1`（自动）
3. 运行游戏
4. 等待20秒
5. 观察重力自动改变
