# 炼色 (LianSe)

一款颜色混合消除类微信/抖音小游戏

## 核心玩法
- 点击相邻方块混合颜色
- 三原色混合规则：红+黄=橙、红+蓝=紫、黄+蓝=绿
- 关卡制：完成目标颜色合成即可过关
- 难度递增

## 技术栈
- Cocos Creator 3.8.1
- TypeScript
- 目标平台：微信小游戏 + 抖音小游戏
