# 手机竖屏配置 - iPhone 14 (750×1334)

## 🎯 项目设置

### 设计分辨率
- **Width**: 750
- **Height**: 1334
- **Fit Height**: 勾选
- **Fit Width**: 不勾选

---

## 📐 GridSystem 配置

### 推荐参数
- **Screen Width Ratio**: 0.95（占屏幕宽度95%）
- **Screen Height Ratio**: 0.5（占屏幕高度50%）
- **Spacing Ratio**: 0.18（方块间隔18%）

### 位置
- **Position**: (0, 0, 0) 或 (0, -50, 0)

### 预期效果
- 可用空间：712×667px
- 方块大小：约60-65px
- 间隔：约11-12px
- 网格总大小：约550×550px

---

## 🔧 UI节点位置建议

```

```

### 敌人系统 (y: 300~400)
```
EnemySystem: (0, 350, 0)
```

### 网格系统 (y: -300~300)
```
GridSystem: (0, 0, 0)  或  (0, -50, 0)
```

### 底部UI (y: -400~-500)
```
PauseButton: (300, -500, 0)
```
