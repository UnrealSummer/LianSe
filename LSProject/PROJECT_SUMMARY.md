## 🎮 游戏流程

### 开始游戏
1. 进入游戏场景
2. 生成8x8网格
3. 随机生成方块（3种颜色）
4. 生成敌人

### 游戏进行
1. 玩家交换方块
2. 检测消除
3. 计算伤害
4. 扣除敌人血量
5. 方块下落填充
6. 检测连击

### 游戏结束
1. 敌人血量归零 → 胜利
2. 时间耗尽 → 失败
3. 显示结算界面
4. 保存进度和金币
