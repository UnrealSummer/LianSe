## 🔧 Bing操作流程

### 步骤1：生成背景图
1. 打开 https://www.bing.com/images/create
2. 输入背景图提示词（英文或中文）
3. 点击"创建"，等待生成（约30秒）
4. 选择最满意的一张
5. 点击下载，保存为 `main_menu_bg_raw.jpg`

### 步骤2：生成Logo
1. 输入Logo提示词
2. 生成后，点击"编辑"
3. 使用"擦除"工具去除背景
4. 使用"裁剪"工具裁剪到合适大小
5. 下载为PNG格式，保存为 `game_logo_raw.png`

### 步骤3：生成按钮
1. 输入按钮提示词
2. 生成后，点击"编辑"
3. 使用"擦除"工具去除背景（如果有）
4. 使用"裁剪"工具精确裁剪按钮
5. 下载为PNG格式

**重要提示：**
- 如果按钮在大图中，使用"裁剪"功能精确裁剪
- 如果背景不是透明的，使用"擦除"功能去除
- 尽量让按钮占满整个画布，方便后续处理

### 步骤4：生成装饰元素
1. 输入装饰元素提示词
2. 生成后编辑去背景
3. 下载为PNG格式

## 🐍 Python后处理脚本

生成后，使用Python脚本处理：

```python
from PIL import Image
import os

# 创建输出目录
os.makedirs("main_menu_assets", exist_ok=True)

# 1. 处理背景图
print("处理背景图...")
bg = Image.open("main_menu_bg_raw.jpg")
bg_resized = bg.resize((750, 1334), Image.Resampling.LANCZOS)
bg_resized.save("main_menu_assets/main_menu_background.jpg", 'JPEG', quality=85, optimize=True)
print("✓ 背景图完成")

# 2. 处理Logo（如果是PNG）
if os.path.exists("game_logo_raw.png"):
    print("处理Logo...")
    logo = Image.open("game_logo_raw.png")
    logo_resized = logo.resize((512, 256), Image.Resampling.LANCZOS)
    logo_resized.save("main_menu_assets/game_logo.png", 'PNG', optimize=True)
    print("✓ Logo完成")

# 3. 处理开始按钮
if os.path.exists("button_start_raw.png"):
    print("处理开始按钮...")
    btn = Image.open("button_start_raw.png")
    btn_resized = btn.resize((450, 100), Image.Resampling.LANCZOS)
    btn_resized.save("main_menu_assets/btn_start.png", 'PNG', optimize=True)
    print("✓ 开始按钮完成")

# 4. 处理次要按钮
if os.path.exists("button_secondary_raw.png"):
    print("处理次要按钮...")
    btn2 = Image.open("button_secondary_raw.png")
    btn2_resized = btn2.resize((350, 80), Image.Resampling.LANCZOS)
    btn2_resized.save("main_menu_assets/btn_secondary.png", 'PNG', optimize=True)
    print("✓ 次要按钮完成")

# 5. 处理装饰元素
if os.path.exists("gem_decoration_raw.png"):
    print("处理装饰元素...")
    gem = Image.open("gem_decoration_raw.png")
    gem_resized = gem.resize((256, 256), Image.Resampling.LANCZOS)
    gem_resized.save("main_menu_assets/gem_decoration.png", 'PNG', optimize=True)
    print("✓ 装饰元素完成")

print("\n所有资源处理完成！")
print("输出目录：main_menu_assets/")
```

## 🎯 使用建议

### 如果生成效果不理想：

1. **背景太亮/太暗：**
   - 调整提示词中的色彩描述
   - 强调"deep dark blue purple"
   - 或使用Python脚本调整亮度

2. **按钮形状不对：**
   - 强调"rounded rectangle"
   - 强调"no text, no icons"
   - 多生成几次选最好的

3. **风格不统一：**
   - 在所有提示词中都加上"sci-fi cartoon style"
   - 保持色彩描述一致
   - 使用相同的关键词

4. **背景去除不干净：**
   - 在Bing编辑器中多次使用"擦除"
   - 或使用在线工具 remove.bg
   - 或使用Photoshop/GIMP手动处理

---

## 📝 注意事项

1. **Bing生成限制：**
   - 每天有生成次数限制
   - 如果用完了，第二天再继续
   - 或使用其他账号

2. **提示词技巧：**
   - 英文提示词效果通常更好
   - 描述要具体明确
   - 强调"no text, no UI elements"避免生成文字

3. **编辑技巧：**
   - 使用Bing内置编辑器预处理
   - 擦除背景时要仔细
   - 裁剪时留一点边距

4. **文件格式：**
   - 背景图用JPG（不需要透明）
   - 其他元素用PNG（需要透明）
   - 注意文件大小控制
