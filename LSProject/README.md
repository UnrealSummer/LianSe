# 炼色 (LianSe) - 三消Roguelike游戏

一个结合三消玩法和Roguelike元素的创新游戏。

---

## 🎮 游戏简介

《炼色》是一款三消+Roguelike游戏，玩家通过消除方块来对敌人造成伤害，同时收集词条来增强自己的能力。游戏特色包括：

- 🎯 **经典三消玩法** - 8x8网格，6种颜色
- 🔄 **创新重力系统** - 4个方向的重力切换
- 📜 **词条系统** - 10种词条，策略性选择
- 👾 **多样敌人** - 8种敌人类型，各有特点
- 💰 **进度系统** - 金币收集，数据持久化

---

## ✨ 核心特色

### 1. 词条系统（Roguelike）
收集和选择词条来增强你的能力：
- 🔥 **烈焰** - 火焰伤害+50%
- ❄️ **寒冰** - 冰冻伤害+50%
- ⚡ **雷电** - 雷电伤害+50%
- 🌊 **洪流** - 水属性伤害+50%
- 🌪️ **狂风** - 风属性伤害+50%
- 🪨 **巨石** - 岩石伤害+50%
- ✨ **神圣** - 光属性伤害+50%
- 🌑 **暗影** - 暗属性伤害+50%
- 💥 **爆裂** - 爆炸伤害+100%
- 🎯 **精准** - 暴击率+20%

### 2. 重力系统
- 上下左右4个方向
- 动态切换重力方向
- 增加策略深度

### 3. 敌人系统
8种不同类型的敌人：
- 普通敌人、精英敌人、Boss
- 速度型、坦克型、法师型
- 狂暴型、召唤型

## 🚀 快速开始

### 1. 打开项目
```bash
# 用Cocos Creator打开项目
# 路径：E:\Project\LianSe\LSProject
```

### 2. 配置方块资源
1. 选中Block预制体
2. 在Block (Script)组件中配置6个Sprite属性
3. 详见：`BLOCK_SPRITE_CONFIG_V2.md`

### 3. 美化UI（可选）
1. 刷新资源管理器
2. 按照 `UI_QUICK_START.md` 应用UI资源
3. 20分钟完成基础美化

### 4. 运行游戏
1. 点击运行按钮
2. 开始游玩！
