## 🔧 在Cocos Creator中使用

### 方法1：使用Sprite Sheet（推荐）

**步骤：**

1. **在Cocos Creator中打开项目**

2. **找到按钮图片**
   ```
   assets → textures → ui → buttons → casual_buttons_sheet.png
   ```

3. **设置为Sprite Sheet**
   - 选中图片
   - 在属性检查器中
   - Type: Sprite Frame
   - 点击"编辑"按钮
   - 使用自动切割或手动切割

4. **切割按钮**
   - 自动切割：设置网格大小
   - 手动切割：框选每个按钮
   - 保存切割结果

5. **使用按钮**
   - 拖拽切割好的Sprite Frame到Button组件
   - 或在代码中引用

---

### 方法2：手动切割（如果需要）

如果Sprite Sheet太大，可以用图片编辑工具手动切割：

**工具推荐：**
- Photoshop
- GIMP（免费）
- Paint.NET（免费）

**步骤：**
1. 打开 `casual_buttons_sheet.png`
2. 选择需要的按钮
3. 裁剪并保存为单独文件
4. 导入到Cocos Creator

## 💡 使用建议

### 按钮选择

**主菜单按钮：**
- 使用大的圆形或方形按钮
- 选择鲜艳的颜色（绿色、蓝色）

**游戏内按钮：**
- 使用小的图标按钮
- 暂停、设置、返回等

**弹窗按钮：**
- 使用中等大小的按钮
- 确认、取消、关闭等

### 颜色使用

**绿色：** 确认、开始、继续  
**红色：** 取消、退出、删除  
**蓝色：** 信息、设置、帮助  
**黄色：** 警告、特殊功能

## 🎯 快速开始

### 示例：创建开始按钮

1. **在Cocos Creator中：**
   - 创建一个Button节点
   - 添加Sprite组件

2. **设置按钮图片：**
   - 从切割好的Sprite Frame中选择
   - 拖拽到Button的Normal Sprite

3. **设置按钮状态：**
   - Normal: 正常状态
   - Pressed: 按下状态（可以用稍暗的颜色）
   - Hover: 悬停状态
   - Disabled: 禁用状态

4. **添加文字：**
   - 在Button下创建Label节点
   - 输入"开始游戏"
   - 设置字体和颜色
