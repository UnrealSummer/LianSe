## 🎮 爽感度优化建议

### 提升爽感的方法

#### 1. 数值优化
**原则：** 稀有度越高，数值提升越夸张

**调整：**
- Common：+3 ~ +5（小幅提升）
- Rare：+10 ~ +50%（明显提升）
- Epic：×2 ~ ×3（爆炸提升）

#### 2. 视觉反馈
**建议：**
- Common：普通文字提示
- Rare：黄色文字 + 小特效
- Epic：红色文字 + 大特效 + 屏幕震动

#### 3. 音效反馈
**建议：**
- Common：普通音效
- Rare：特殊音效
- Epic：爆炸音效 + 背景音乐变化

#### 4. 触发频率
**平衡：**
- Common：高频触发（每次消除）
- Rare：中频触发（特定条件）
- Epic：低频触发（稀有条件）

## 🎯 词条选择算法

### 权重系统
```typescript
function selectModifiers(count: number): IModifier[] {
    const pool = [];
    
    // Common: 60%
    const commonModifiers = getModifiersByRarity('common');
    for (let i = 0; i < 6; i++) {
        pool.push(...commonModifiers);
    }
    
    // Rare: 30%
    const rareModifiers = getModifiersByRarity('rare');
    for (let i = 0; i < 3; i++) {
        pool.push(...rareModifiers);
    }
    
    // Epic: 10%
    const epicModifiers = getModifiersByRarity('epic');
    pool.push(...epicModifiers);
    
    // 随机抽取
    const shuffled = pool.sort(() => Math.random() - 0.5);
    return shuffled.slice(0, count);
}
```
