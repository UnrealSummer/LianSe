# 《炼色》开发计划

## 📋 项目概况

**项目名称：** 炼色 (LianSe)  
**类型：** 三消+Roguelike微信小游戏  
**当前版本：** v0.4.0-ui-fixes  
**开发阶段：** Alpha（核心功能完成，需要优化和扩展）

---

- [ ] 调整金币掉落
- [ ] 调整词条出现概率
- [ ] 记录测试数据

#### 1.3 排行榜完善

- [ ] 添加排行榜加载动画

#### 1.4 Bug修复

## 🚀 中期目标（2-4周）

### 阶段2：内容扩展 ⭐⭐⭐⭐

**优先级：高**

#### 2.1 更多词条
- [ ] 设计10-15个新词条
- [ ] 实现新词条效果
- [ ] 测试词条平衡性
- [ ] 添加词条图标和特效

**词条创意：**
- 攻击类：穿透、溅射、吸血
- 防御类：护盾、反伤、闪避
- 特殊类：时间停止、复活、双倍奖励

#### 2.2 更多敌人类型
- [ ] 设计5-8种新敌人
- [ ] 实现敌人特殊能力
- [ ] 添加敌人美术资源
- [ ] 测试敌人难度

**敌人创意：**
- 快速型：低血高速
- 坦克型：高血低速
- 法师型：远程攻击
- Boss型：多阶段战斗

#### 2.3 关卡系统扩展
- [ ] 增加关卡数量（目标：20-30关）
- [ ] 设计关卡主题（森林、沙漠、雪山等）
- [ ] 添加关卡特殊机制
- [ ] 实现关卡解锁系统

#### 2.4 成就系统
- [ ] 设计成就列表（20-30个）
- [ ] 实现成就检测
- [ ] 添加成就UI
- [ ] 成就奖励（金币、称号）

**成就创意：**
- 首次通关
- 连击达人（连击100+）
- 富豪（累计10000金币）
- 词条收集家（收集所有词条）

**预计时间：** 1-2周  
**完成标准：** 内容丰富，可玩性提升
