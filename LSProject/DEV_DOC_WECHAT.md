## 📋 开发规范

### 1. 代码规范

#### 微信API使用
```typescript
// 始终检查wx是否存在
if (typeof wx !== 'undefined') {
    wx.login({...});
} else {
    console.log('Not in WeChat');
}
```

#### 错误处理
```typescript
// 所有微信API都要有错误处理
wx.someAPI({
    success: (res) => {},
    fail: (err) => {
        console.error('API failed:', err);
    }
});
```

---

### 2. 资源规范

#### 图片
- PNG/JPG格式
- 使用TinyPNG压缩
- 合并到图集

#### 音频
- MP3格式
- 128kbps码率
- 背景音乐 < 2分钟

#### 字体
- 优先使用系统字体
- 或位图字体（只包含需要的字符）

---

### 3. 性能规范

#### 包体大小
- 首包 < 4MB（强制）
- 使用分包加载
- 远程资源

#### 性能指标
- 启动时间 < 3秒
- 帧率 ≥ 30 FPS
- 内存 < 200MB

### 开发时必须记住
