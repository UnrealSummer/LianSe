## 方块设计规范

### 1. 普通方块（6种颜色）

#### 基础形状：圆角正方形
```
尺寸: 64x64 像素
圆角: 8px
边框: 2px 白色高光
```

#### 颜色方案
```
🟥 红色 (RED)     #FF3B30  - 热情、活力
🟨 黄色 (YELLOW)  #FFCC00  - 明亮、欢快
🟦 蓝色 (BLUE)    #007AFF  - 冷静、清爽
🟧 橙色 (ORANGE)  #FF9500  - 温暖、友好
🟪 紫色 (PURPLE)  #AF52DE  - 神秘、优雅
🟩 绿色 (GREEN)   #34C759  - 自然、和谐
```

#### 视觉效果
```
┌──────────┐
│  ╱╲      │  ← 高光（左上角）
│ ╱  ╲     │
│ ▓▓▓▓     │  ← 主体颜色（渐变）
│ ▓▓▓▓     │
│  ╲╱      │  ← 阴影（右下角）
└──────────┘
```

### 2. 特殊方块

#### 🌈 彩虹方块
```
效果: 渐变彩虹色，会循环变色
动画: 红→橙→黄→绿→蓝→紫 (0.5秒/色)
功能: 可以和任意颜色匹配
```

#### 🪨 石头方块
```
颜色: 灰色 #646464
纹理: 石头裂纹
效果: 不可移动，不可消除
```

#### ❄️ 冰冻方块
```
基础: 原方块颜色 + 蓝色调
覆盖层: 半透明浅蓝色 rgba(180, 220, 255, 0.4)
边框: 白色冰霜边框
裂纹: 白色放射状裂纹（1层冰冻时显示）
```

## 特效设计

### 1. 消除特效
```
阶段1: 方块放大 (1.0 → 1.2) 0.1秒
阶段2: 粒子爆炸 (同色小方块飞散) 0.2秒
阶段3: 方块缩小消失 (1.2 → 0) 0.1秒
```

### 2. 冰冻特效
```
阶段1: 蓝色波纹从中心扩散 0.2秒
阶段2: 冰层覆盖 0.1秒
阶段3: 冰霜边框出现 0.1秒
```

### 3. 解冻特效
```
阶段1: 裂纹出现 0.1秒
阶段2: 裂纹扩大 0.2秒
阶段3: 冰层破碎消失 0.2秒
```

## 动画时序

### 交换动画
```
0.0s: 开始交换
0.2s: 交换完成
0.3s: 检查匹配
0.4s: 开始消除（如果匹配）
```

### 消除动画
```
0.0s: 方块放大
0.1s: 粒子爆炸
0.2s: 方块缩小
0.4s: 消除完成
0.5s: 方块下落
```

### 下落动画
```
速度: 800 像素/秒
缓动: easeInQuad
落地: 轻微弹跳效果
```
