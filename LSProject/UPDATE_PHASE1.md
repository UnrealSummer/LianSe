# Phase 1 更新 - 多重目标 + 分数系统

## ✨ 新增功能

### 1. 分数系统
- **基础分数：** 每次混合 +10 分
- **连击加成：** 连续混合有倍数加成（1.5倍递增）
  - 第1次混合：10分
  - 第2次连击：15分
  - 第3次连击：20分
  - ...
- **打断连击：** 点击无法混合的方块会重置连击

### 2. 多重目标
- **第1关：** 合成2个橙色，达到50分
- **第2关：** 合成2个橙色+2个紫色，达到100分
- **第3关：** 合成2个橙色+2个紫色+2个绿色，达到150分
- **第4关：** 合成3个橙色+2个紫色，达到200分

### 3. 胜利条件
必须同时满足：
- ✅ 分数达标
- ✅ 所有目标颜色数量达标

### 4. 实时进度显示
- 目标面板显示各颜色完成情况（✅/⭕）
- 分数实时更新
- 步数倒计时

### 5. 自动进关
过关后3秒自动进入下一关

## 🎮 在Cocos Creator中设置

### 需要添加的UI（重要！）

1. **在UI节点下添加 `ScoreLabel`：**
   - 创建一个Label节点，命名为 `ScoreLabel`
   - 设置字体大小（建议30-40）
   - 位置：放在TargetLabel旁边或下方

2. **连接到GameManager：**
   - 选中 `GameManager` 节点
   - 找到 `GameManager` 组件
   - 把 `ScoreLabel` 拖到 `scoreLabel` 属性框

3. **调整TargetLabel大小：**
   - 现在目标文本更多了（多行显示）
   - 建议把Label的高度调大一些
   - 或者减小字体让它显示更多行

## 🎯 策略深度提升

### 现在玩家需要考虑：

1. **资源分配：**
   - 红色既能做橙色（红+黄），也能做紫色（红+蓝）
   - 先做哪个？怎么平衡？

2. **分数与目标平衡：**
   - 只刷分可能达不到目标数量
   - 只做目标可能分数不够
   - 需要权衡

3. **连击管理：**
   - 连续混合能快速提分
   - 但要规划好路径，避免打断

4. **步数压力：**
   - 步数有限，不能随便乱混
   - 失败会明确告诉你差在哪里
