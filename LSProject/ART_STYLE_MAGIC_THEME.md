# 《技能消消消》美术风格 - 魔法主题

## 🎨 核心风格

**魔法主题 + 深色背景 + 鲜艳魔法元素**

## 🔮 风格关键词

1. **魔法** - 魔法主题的神秘氛围
2. **深邃** - 深色魔法背景
3. **鲜艳** - 高饱和度的魔法宝石
4. **发光** - 魔法渐变和发光效果
5. **圆润** - 统一的圆角设计
6. **半透明** - UI元素的层次感

**背景：**
- 深蓝紫色魔法夜空渐变：#1a1a2e → #16213e → #0f3460
- 魔法粒子/星星点缀

**魔法宝石（6种）：**
- 红色魔法：#FF6B6B → #FF8E53

**UI元素：**
- 紫色魔法渐变（主按钮）：#667eea → #764ba2
- 蓝绿魔法渐变（次要按钮）：#4ECDC4 → #44A08D

## ✨ 视觉特点

- **魔法渐变** - 所有元素都有魔法渐变效果
