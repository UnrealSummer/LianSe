# 美术资源解决方案 - 工作流程

## 概述

这是《炼色》项目的美术资源标准工作流程，适用于任何需要美术资源的游戏项目。

---

## 工作流程

### 第一步：需求梳理

1. **分析项目代码**
   - 查看所有涉及美术资源的代码文件
   - 列出所有资源类型（方块、UI、特效、敌人等）
   - 记录每种资源的规格要求（尺寸、格式、状态）

2. **检查现有资源**
   - 遍历项目资源目录
   - 标记已有资源 ✅
   - 标记缺失资源 ❌
   - 评估现有资源质量和风格统一性

3. **创建需求清单**
   - 按优先级分类（P0/P1/P2）
   - 记录详细规格（尺寸、格式、风格）
   - 列出资源数量和变体

**输出文档：** `[project]_art_requirements.md`

---

### 第二步：确定风格

1. **选择参考资源**
   - 从现有资源中选择最佳样本
   - 或从目标游戏中截图参考
   - 确定色彩方案、形状、光影风格

2. **定义风格指南**
   - 色彩方案（主色、辅助色、强调色）
   - 视觉特征（形状、光泽、阴影、边缘）
   - 尺寸规范（标准尺寸、缩放规则）

3. **准备AI提示词模板**
   - 为每种资源类型编写提示词
   - 包含风格、格式、细节描述
   - 测试并优化提示词

**输出文档：** `art_resources/README.md`（风格参考部分）

---

### 第三步：资源收集

#### 3.1 搜索免费资源

**推荐资源站：**
- **Kenney.nl** - 高质量游戏素材包
- **OpenGameArt.org** - 开源游戏美术
- **itch.io** - 独立开发者资源
- **Freepik** - 矢量图和插画

**搜索技巧：**
- 使用英文关键词（match-3, puzzle, gem, block）
- 筛选条件：免费、商用许可、PNG格式
- 下载多个候选资源备选

**保存位置：** `art_resources/downloaded/`

#### 3.2 AI生成资源

**推荐工具：**
- **Leonardo.ai** - 游戏资产生成（推荐）
- **Midjourney** - 高质量插画
- **DALL-E 3** - 精确控制
- **Stable Diffusion** - 本地部署

**生成流程：**
1. 使用准备好的提示词模板
2. 生成多个变体（3-5个）
3. 选择最佳结果
4. 必要时迭代优化

**保存位置：** `art_resources/generated/`

---

### 第四步：筛选整理

1. **质量检查**
   - 尺寸是否正确
   - 透明背景是否干净
   - 风格是否统一
   - 颜色是否准确

2. **批量处理**
   - 统一尺寸（使用Photoshop/GIMP）
   - 优化文件大小（TinyPNG）
   - 统一命名规范

3. **分类整理**
   - 按资源类型分文件夹
   - 使用规范命名
   - 记录资源来源（版权信息）

**保存位置：** `art_resources/selected/`

---

### 第五步：集成测试

1. **复制到项目**
   - 将筛选后的资源复制到项目目录
   - 保持原有目录结构
   - 备份原有资源（如果替换）

2. **配置引用**
   - 在编辑器中关联资源
   - 更新代码中的资源路径
   - 检查资源加载是否正常

3. **游戏内测试**
   - 运行游戏检查显示效果
   - 测试不同分辨率
   - 验证动画和特效

4. **调整优化**
   - 根据测试结果微调
   - 必要时重新生成或查找
   - 记录最终版本

## 命名规范

### 通用规则
- 全小写字母
- 使用下划线分隔
- 描述性命名
- 包含类型和变体

### 示例
```
block_red.png              # 红色方块
block_frozen_overlay.png   # 冰冻覆盖层
effect_explosion_01.png    # 爆炸特效第1帧
enemy_boss_idle.png        # Boss敌人待机
ui_button_primary.png      # 主按钮
```

## AI提示词技巧

### 基础结构
```
[Style] + [Subject] + [Details] + [Format] + [Technical]
```

### 关键词库

**风格关键词：**
- Cute cartoon, Casual game, Mobile game asset
- Bright colors, Glossy finish, Soft shadows
- Rounded edges, Smooth gradient

**格式关键词：**
- PNG transparent background
- 64x64 pixels, Centered
- High resolution, Clean edges

**质量关键词：**
- Professional, High quality, Game-ready
- Consistent style, Polished, Optimized

### 优化技巧
1. **具体化** - 越详细越好
2. **参考** - 提供风格参考图
3. **迭代** - 多次生成选最佳
4. **负面提示** - 排除不想要的元素

## 版权注意事项

### 免费资源
- 检查许可协议（CC0, CC-BY, MIT等）
- 商用是否允许
- 是否需要署名
- 记录资源来源

### AI生成
- 确认平台的版权政策
- 商用权限是否包含
- 保存生成记录
- 必要时购买商用授权

### 自制资源
- 保留原始文件（PSD/AI）
- 记录创作过程
- 版本控制

## 常见问题

### Q: 找不到合适的免费资源怎么办？
A: 优先使用AI生成，或考虑购买付费资源包。

### Q: AI生成的资源风格不统一？
A: 使用相同的提示词模板，保持参数一致，必要时手动调整。

### Q: 资源文件太大怎么办？
A: 使用TinyPNG压缩，或降低分辨率（保持清晰度）。

### Q: 如何快速测试资源效果？
A: 在编辑器中直接替换，运行游戏预览，不满意立即回滚。
