# 《炼色》品质提升计划

## 🎯 目标
解决"目标感不足"和"爽感不够"的问题，打造完整的游戏体验。

---

## 📋 实施清单

### Phase 1: UI/UX 改进（立即着手）

#### 1.1 目标进度可视化
- [ ] 为每个目标颜色添加进度条
- [ ] 实时更新进度（每次混合后）
- [ ] 达成目标时高亮/打勾动画
- [ ] 总体进度百分比显示

#### 1.2 分数反馈增强
- [ ] 分数跳动动画（+10, +20等飞出）
- [ ] 大数字渐隐效果
- [ ] 不同分数不同颜色（10分=白色，20分=黄色，40分+=红色）

#### 1.3 连锁倍数显示
- [ ] 屏幕中央显示「×2连锁！」「×4连锁！」
- [ ] 字体大小随倍数增大
- [ ] 颜色渐变效果（2连=黄，3连=橙，4连+=红）

---

### Phase 2: 音效系统

#### 2.1 基础音效
- [ ] 点击方块音效（轻快）
- [ ] 混合成功音效（清脆）
- [ ] 掉落音效（柔和）
- [ ] 关卡完成音效（胜利）

#### 2.2 进阶音效
- [ ] 连锁音效（层次递增）
- [ ] 强化色混合音效（特殊）
- [ ] 彩虹方块出现音效（稀有）
- [ ] 目标达成音效（提示音）

#### 2.3 音效实现方式
- 使用 Web Audio API 生成程序化音效
- 或使用免费音效库（freesound.org, zapsplat.com）
- Cocos Creator AudioSource 组件

## 📊 自测标准

### 功能测试
- [ ] 所有音效正常播放
- [ ] 粒子效果不卡顿
- [ ] 动画流畅（60fps）
- [ ] 进度条准确更新

### 体验测试
- [ ] 玩5局，每次都有"爽感"

- [ ] 连锁反馈明显
- [ ] 没有视觉/听觉疲劳

### 性能测试
- [ ] 手机浏览器流畅运行
- [ ] 资源加载时间<2秒
- [ ] 内存占用合理
