## 📐 资源规范

### 尺寸规范

| 资源类型 | 推荐尺寸 | 格式 | 备注 |
|---------|---------|------|------|
| 方块 | 128x128 | PNG | 透明背景 |
| 敌人 | 256x256 | PNG | 透明背景 |
| UI面板 | 可变 | PNG | 9-slice支持 |
| 图标 | 64x64 | PNG | 透明背景 |
| 背景 | 1920x1080 | JPG | 可压缩 |
| 特效 | 可变 | PNG | 序列帧 |

### 命名规范

```
类型_名称_状态.png

示例：
- block_red_normal.png
- block_red_selected.png
- enemy_chaos_idle.png
- enemy_chaos_hit.png
- ui_panel_main.png
- icon_coin.png
- effect_explosion_01.png
```

### 文件大小控制

- **单个图片：** < 50KB
- **序列帧：** 每帧 < 20KB
- **背景图：** < 200KB
- **总包体：** < 4MB（微信小游戏限制）

## 🛠️ 资源优化

### 图片压缩工具

1. **TinyPNG** (在线)
   - https://tinypng.com
   - 无损压缩PNG
   - 可减少70%文件大小

2. **ImageOptim** (Mac)
   - 批量压缩
   - 保持质量

3. **PNGGauntlet** (Windows)
   - 批量优化
   - 免费开源

### Cocos Creator设置

```javascript
// 纹理压缩设置
- 格式：PNG
- 压缩：开启
- 预乘Alpha：开启
- 生成Mipmap：关闭（2D游戏）
```

## 📦 资源导入流程

### 1. 准备资源
```bash
# 目录结构
assets/
  textures/
    blocks/        # 方块
    enemies/       # 敌人
    effects/       # 特效
    ui/           # UI元素
    backgrounds/  # 背景
    icons/        # 图标
```

### 2. 导入Cocos Creator
1. 拖拽文件到对应目录
2. 等待自动生成.meta文件
3. 设置纹理属性
4. 创建Sprite Frame

### 3. 使用资源
```typescript
// 在代码中引用
@property(SpriteFrame)
blockSprite: SpriteFrame = null;

// 动态加载
resources.load('textures/blocks/red', SpriteFrame, (err, sprite) => {
    this.sprite.spriteFrame = sprite;
});
```

## 💡 实用技巧

### 1. 快速原型
- 先用纯色方块
- 用文字代替图标
- 专注玩法，后期美化

### 2. 统一风格
- 选定一个参考游戏
- 保持色调一致
- 使用相同的边框/阴影

### 3. 渐进优化
- 先完成基础功能
- 逐步替换资源
- 收集玩家反馈

### 4. 性能优先
- 合并图集
- 压缩纹理
- 减少Draw Call
