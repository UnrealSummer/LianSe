### 实施 Phase 1 + 2（10:20-10:35）

#### 创建的文件

**1. UIManager.ts**（4.8KB）
负责所有UI视觉反馈：
```typescript
// 核心功能
- showScorePopup(score, position, isChain)  // 分数弹出动画
- showComboPopup(chainLevel)                // 连锁倍数显示
- screenShake(intensity)                    // 屏幕震动
- updateProgressBar(color, current, target) // 进度条更新
```

**特点：**
- 分数飞出：向上移动100px + 0.8秒渐隐
- 分数着色：10分=白，20分=黄，40分+=红
- 连锁提示：字体大小递增（60→70→80），颜色变化（黄→橙→红）
- 弹跳动画：放大1.2倍 + backOut缓动

**2. AudioManager.ts**（5.2KB）
程序化音效生成器（Web Audio API）：
```typescript
// 音效列表
- playClick()        // 400Hz 正弦波
- playMix(chainLevel)// 600Hz 三角波（连锁升高）
- playDrop()         // 300→150Hz 下降音
- playWin()          // C-E-G和弦 + 高音C
- playFail()         // 400→100Hz 锯齿波
- playChain(level)   // 快速上升音阶
- playEnhanced()     // 800Hz + 1200Hz 双重和音
- playRainbow()      // 800-1200Hz 循环闪烁
```

**优点：**
- 零依赖，无需外部音效文件
- 连锁层数影响音调（越高越尖）
- 主音量30%，避免吵闹

#### 修改的文件

**GameManager.ts**
- 导入 UIManager 和 AudioManager
- 添加两个 @property 引用
- 在关键位置集成反馈：
  ```typescript
  // 点击方块
  this.audioManager.playClick();
  
  // 混合成功
  this.audioManager.playMix(chainCount);
  this.uiManager.showScorePopup(earnedScore, worldPos, isChain);
  
  // 连锁触发
  this.uiManager.showComboPopup(chainCount);
  this.audioManager.playChain(chainCount);
  this.uiManager.screenShake(chainCount * 0.2);
  
  // 强化色
  this.audioManager.playEnhanced();
  
  // 胜利/失败
  this.audioManager.playWin() / playFail();
  ```

1. **程序化音效生成** - 无需外部文件，纯Web Audio API

### 经验总结

**好的设计原则：**
- 渐进式反馈：分数飞出→连锁提示→震动，层次递进
- 多感官结合：视觉（UI）+ 听觉（音效）+ 触觉（震动）
- 参数化控制：同一系统适配不同强度

**技术选型：**
- Web Audio API比加载外部音效文件更灵活
- 程序化生成可以根据游戏状态实时调整
- 文本UI在prototype阶段比图形UI更快迭代
