# 微信小游戏构建配置指南

## 🎯 目标

在Cocos Creator中配置并构建微信小游戏版本

---

## 📋 前置准备

### 1. 安装微信开发者工具

**下载地址：**
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

**选择：** 稳定版 Stable Build

**安装后：**
- 打开微信开发者工具
- 使用微信扫码登录

---

### 2. 注册微信小游戏

**如果还没有AppID：**

1. 访问：https://mp.weixin.qq.com/
2. 注册小程序账号
3. 选择"小游戏"类型
4. 完成注册流程
5. 获取AppID

**测试用AppID：**
- 如果只是测试，可以使用测试号
- 微信开发者工具会提供测试AppID

---

## 🛠️ Cocos Creator配置步骤

### 第一步：打开项目设置（2分钟）

1. **打开Cocos Creator**
2. **打开《炼色》项目**
   - 路径：E:\Project\LianSe\LSProject
3. **打开项目设置**
   - 菜单：项目 → 项目设置
   - 或快捷键：Ctrl + Shift + P

---

### 第二步：配置基础设置（3分钟）

#### 1. 设计分辨率
```
项目设置 → 项目数据
- 设计分辨率：750 x 1334
- 适配屏幕宽度：勾选
- 适配屏幕高度：勾选
```

#### 2. 屏幕方向
```
项目设置 → 项目数据
- 屏幕方向：Portrait（竖屏）
```

#### 3. 启动场景
```
项目设置 → 项目数据
- 启动场景：MainMenu
```

---

### 第三步：配置构建发布（5分钟）

1. **打开构建发布面板**
   - 菜单：项目 → 构建发布
   - 或快捷键：Ctrl + Shift + B

2. **选择发布平台**
   - 平台：微信小游戏

3. **配置构建选项**

#### 基础配置
```
发布平台：微信小游戏
构建任务名称：wechat-game
起始场景：MainMenu（自动选择）
```

#### 微信小游戏配置
```
AppID：
- 如果有正式AppID → 填入
- 如果测试 → 留空或填入测试AppID

游戏名称：炼色

游戏版本号：1.0.0

设备方向：Portrait（竖屏）
```

#### 高级选项
```
调试模式：
- 开发时：勾选
- 发布时：取消勾选

Source Maps：
- 开发时：勾选
- 发布时：取消勾选

内联所有SpriteFrame：
- 取消勾选（减小包体）

MD5 Cache：
- 勾选（版本更新）

分离引擎：
- 勾选（减小首包）

压缩纹理：
- 根据需要选择
```

---

### 第四步：构建项目（2分钟）

1. **点击"构建"按钮**
   - 等待构建完成

2. **检查构建结果**
   - 构建成功后，会显示"构建成功"
   - 构建输出目录：build/wechat-game/

## 🎯 构建选项详解

### 调试模式
**开启：**
- 包含调试信息
- 可以使用console.log
- 包体更大

**关闭：**
- 移除调试信息
- 包体更小
- 性能更好

**建议：** 开发时开启，发布时关闭

---

### Source Maps
**开启：**
- 可以调试TypeScript源码
- 包体更大

**关闭：**
- 只能调试编译后的JS
- 包体更小

**建议：** 开发时开启，发布时关闭

---

### 内联所有SpriteFrame
**开启：**
- 所有图片信息内联到JSON
- 首次加载更快
- 包体更大

**关闭：**
- 图片信息分离
- 包体更小
- 推荐

**建议：** 关闭

---

### MD5 Cache
**开启：**
- 文件名添加MD5后缀
- 支持版本更新
- 推荐

**关闭：**
- 文件名不变
- 可能有缓存问题

**建议：** 开启

---

### 分离引擎
**开启：**
- 引擎代码分离到cocos-js/
- 减小首包大小
- 推荐

**关闭：**
- 引擎代码打包到game.js
- 首包更大

**建议：** 开启

---

## 📦 分包配置（如果需要）

### 什么时候需要分包？

**如果首包 > 4MB，必须分包！**

### 如何配置分包？

#### 1. 在Cocos Creator中配置

```
资源管理器 → 右键文件夹 → 配置为分包
```

**建议分包结构：**
```
assets/
├── scenes/
│   ├── MainMenu.scene（主包）
│   └── Main.scene（分包1）
├── textures/
│   ├── ui/（主包）
│   └── blocks/（分包1）
└── audio/（分包2）
```

#### 2. 在game.json中配置

```json
{
  "subpackages": [
    {
      "name": "game",
      "root": "subpackages/game/"
    },
    {
      "name": "audio",
      "root": "subpackages/audio/"
    }
  ]
}
```

## 🐛 常见问题

### Q1: 构建失败？
**A:** 
1. 检查Cocos Creator版本（推荐3.8+）
2. 检查项目路径（不要有中文）
3. 查看构建日志错误信息
4. 清理build目录重新构建

### Q2: 包体超过4MB？
**A:**
1. 检查资源大小
2. 压缩图片
3. 配置分包
4. 使用远程资源

### Q3: 微信开发者工具打不开？
**A:**
1. 检查项目路径是否正确
2. 检查game.json是否存在
3. 重新构建项目

### Q4: 预览时白屏？
**A:**
1. 检查启动场景是否正确
2. 查看控制台错误信息
3. 检查资源是否加载成功

### Q5: 真机测试卡顿？
**A:**
1. 关闭调试模式
2. 优化性能
3. 减少DrawCall
4. 使用对象池
