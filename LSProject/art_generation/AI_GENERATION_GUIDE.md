## 🎨 生成技巧

### 提示词优化
1. **使用英文提示词** - 效果通常更好
2. **描述要具体** - 包含颜色代码、风格关键词
3. **强调"no text, no UI elements"** - 避免生成文字
4. **添加"professional game art"** - 提升质量
5. **添加"high quality"** - 提升细节

### 如果效果不理想
1. **多生成几次** - 选择最好的一张
2. **调整提示词** - 添加或删除关键词
3. **使用"编辑"功能** - 在Bing中直接修改
4. **组合多个结果** - 取不同图片的优点

### Bing编辑器技巧
1. **擦除背景** - 使用"擦除"工具，多次点击去除背景
2. **精确裁剪** - 使用"裁剪"工具，留一点边距
3. **调整亮度** - 如果太暗或太亮，使用"调整"功能
4. **导出PNG** - 确保选择PNG格式保留透明度
