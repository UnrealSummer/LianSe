# 测试文档

## 自动化测试

### 使用方法

1. **在场景中添加TestRunner组件：**
   - 在Hierarchy中找到Canvas或创建一个空节点
   - 添加 `TestRunner` 组件
   - 拖拽 GameManager 和 GridManager 到对应属性
   - （可选）创建一个Label显示测试结果

2. **运行测试：**
   - 点击编辑器的"运行"按钮
   - 测试会自动执行
   - 查看控制台输出

3. **查看结果：**
   ```
   📊 测试结果汇总
   ====================================
   总测试数: 20
   ✅ 通过: 20
   ❌ 失败: 0
   通过率: 100.0%
   ====================================
   ```

### 测试原则

1. **每次修改代码后，运行测试**
   - 确保没有破坏现有功能
   - 发现问题立即修复

2. **添加新功能时，先写测试**
   - 明确预期行为
   - 防止回归

3. **测试失败时，不要提交代码**
   - 先修复测试
   - 确保通过率100%

### 如何添加新测试

在 `TestRunner.ts` 中添加新的测试方法：

```typescript
testYourFeature() {
    console.log('\n=== 测试：你的功能 ===');
    
    // 设置测试环境
    this.gameManager.initLevel(1);
    
    // 执行操作
    const result = someOperation();
    
    // 验证结果
    this.assert(
        result === expectedValue,
        '测试名称',
        `预期: ${expectedValue}, 实际: ${result}`
    );
}
```

然后在 `runAllTests()` 中调用：
```typescript
runAllTests() {
    this.testLevelInitialization();
    this.testGridIntegrity();
    this.testColorMixing();
    this.testYourFeature(); // 添加你的测试
    this.showResults();
}
```

## 为什么需要测试

### 这次"方块不消失"问题的教训

**没有测试时：**
- ❌ 手动运行游戏
- ❌ 截图控制台
- ❌ 描述问题
- ❌ 猜测原因
- ❌ 耗时1.5天

**有测试的话：**
- ✅ 运行测试：10秒
- ✅ 看到：`❌ 第1关 - 无僵尸方块 (预期节点数: 25, 实际: 89)`
- ✅ 立即知道：第1关有64个僵尸方块（8×8 + 5×5 = 89）
- ✅ 定位问题：初始化重复
- ✅ 修复：30分钟

**效率提升：** 48倍

### 长期收益

- 💰 **节省时间：** 每次改代码10秒验证，而不是手动测试
- 🛡️ **防止回归：** 新功能不会破坏旧功能
- 📝 **文档作用：** 测试就是最好的功能说明
- 🎯 **质量保证：** 部署前确保通过率100%
