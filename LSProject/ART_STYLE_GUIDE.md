# 《技能消消消》游戏美术风格规范文档

## 📋 文档说明

本文档定义了《技能消消消》游戏的完整美术风格规范，包括色彩、形状、效果、尺寸等所有设计要素。

## 🎯 核心美术制作工作流（最重要）

### 游戏基本信息

**游戏名称：** 技能消消消（不是"炼色"！）  
**类型：** 三消 + Roguelike  
**平台：** 微信小游戏（竖屏）  
**风格：** 魔法主题

### Bing AI生成工作流

**工具：** Bing Image Creator (https://www.bing.com/images/create)

**核心步骤：**

1. **打开Bing Image Creator**
   - 访问 https://www.bing.com/images/create
   - 登录Microsoft账号

2. **选择模型和设置**
   - **模型：** 选择 GPT-4o（最新最强模型）
   - **纵横比：** 选择"纵"（2:3，竖屏，适合手机游戏）
   - **质量：** 默认高质量

3. **输入提示词（使用成功的模板）**
   
   **标准提示词模板（基于"技能消消消"成功案例）：**
   ```
   vertical mobile game main menu ui for fantasy roguelike match-3 game,
   750x1334 portrait layout,
   magic academy interior background with stone walls and floating colorful gems,
   game title "技能消消消" at top in stylized fantasy font with magical glow,
   4 wooden-framed buttons stacked vertically in center with chinese text (开始游戏/排行榜/设置/退出),
   warm lighting, magical atmosphere,
   bookshelves and spell ingredients as decoration,
   hand-drawn indie game style,
   clean readable ui
   ```
   
   **关键词说明：**
   - `vertical mobile game main menu ui` - 竖屏手机游戏主菜单UI
   - `750x1334 portrait layout` - 具体尺寸
   - `magic academy interior` - 魔法学院室内（具体场景）
   - `stone walls and floating colorful gems` - 石墙和漂浮的彩色宝石
   - `game title at top in stylized fantasy font with magical glow` - 顶部标题+魔法发光
   - `wooden-framed buttons stacked vertically` - 木框按钮垂直堆叠
   - `warm lighting, magical atmosphere` - 温暖光照，魔法氛围
   - `hand-drawn indie game style` - 手绘独立游戏风格
   - `clean readable ui` - 清晰可读的UI

4. **生成图片**
   - 点击"创建"按钮
   - 等待30-60秒生成
   - 会生成1张图片（GPT-4o模式）

5. **编辑和分离元素（核心步骤）**
   - 选择生成的原型图
   - 点击"编辑"按钮进入编辑模式
   - **使用"擦除"工具：** 去除不需要的背景或元素
   - **使用"裁剪"工具：** 精确裁剪需要的部分
   - **实现元素分离：** 从原画图中分离出背景、按钮、图标等独立元素

6. **下载保存**
   - 下载为PNG格式（保留透明度）
   - 或JPG格式（背景图）
   - 保存到项目目录

**关键技巧：**
- **一图多用：** 在一张原画图中生成多个元素，然后通过编辑分离
- **背景分离：** 使用"擦除"工具去除背景，得到独立UI元素
- **精确裁剪：** 使用"裁剪"工具提取特定区域
- **保持风格统一：** 所有元素在同一张原画图中生成，风格自然统一

**示例工作流：**
```
生成一张包含背景+标题+按钮的完整原型图
↓
编辑1：擦除标题和按钮，保留背景 → 导出背景图
↓
编辑2：裁剪标题区域 → 导出Logo素材
↓
编辑3：裁剪按钮区域 → 导出按钮素材
```

## ✨ 视觉效果规范

### 1. 渐变效果
```
渐变类型：线性渐变（Linear Gradient）

渐变方向：
- 宝石方块：从上到下（垂直）
- 按钮：从上到下（垂直）
- 信息显示：从左到右（水平）
- 血条：从左到右（水平）

渐变实现：
- 逐像素绘制，平滑过渡
- 起始色到结束色的线性插值
- 公式：color = start_color + (end_color - start_color) * progress
```

### 2. 高光效果
```
应用对象：宝石方块

高光位置：
- 顶部偏上区域
- 距离顶部：40px
- 宽度：内容区宽度的70%

高光形状：
- 椭圆形
- 高度：80px（渐变衰减）

高光颜色：
- 白色 RGB(255, 255, 255)
- 透明度：80（顶部）→ 0（底部）
- 渐变衰减：100层，每层透明度递减
```

### 3. 发光效果
```
应用对象：激活状态的按钮、血条

发光实现：
- 多层边框叠加（5-8层）
- 每层向外扩展1-2px
- 透明度递减：80 → 0
- 颜色：与元素主色相同

发光公式：
- alpha = base_alpha * (1 - layer_index / total_layers)
- offset = layer_index * 1px
```

### 4. 阴影效果
```
内阴影（空白格子）：
- 位置：内部边缘
- 颜色：黑色 RGB(0, 0, 0)
- 透明度：30（顶部）→ 0（底部）
- 宽度：3层，每层1px
- 向内收缩

外阴影（可选）：
- 暂未使用，保留扩展
```

### 5. 边框效果
```
标准边框：
- 宽度：2-8px（根据元素大小）
- 颜色：白色，透明度50-150
- 位置：元素外边缘
- 圆角：与元素圆角相同

发光边框：
- 多层叠加（见发光效果）
- 仅用于激活状态
```

## 🔧 技术实现规范

### 1. 渐变实现代码模板
```python
# 垂直渐变（从上到下）
for y in range(height):
    progress = y / height
    r = int(color1[0] + (color2[0] - color1[0]) * progress)
    g = int(color1[1] + (color2[1] - color1[1]) * progress)
    b = int(color1[2] + (color2[2] - color1[2]) * progress)
    draw.rectangle([0, y, width, y + 1], fill=(r, g, b, 255))

# 水平渐变（从左到右）
for x in range(width):
    progress = x / width
    r = int(color1[0] + (color2[0] - color1[0]) * progress)
    g = int(color1[1] + (color2[1] - color1[1]) * progress)
    b = int(color1[2] + (color2[2] - color1[2]) * progress)
    draw.rectangle([x, 0, x + 1, height], fill=(r, g, b, 255))
```

### 2. 圆角遮罩实现
```python
# 创建圆角遮罩
mask = Image.new('L', (width, height), 0)
```

### 3. 高光效果实现
```python
# 创建高光层
highlight = Image.new('RGBA', (size, size), (0, 0, 0, 0))
highlight_draw = ImageDraw.Draw(highlight)

# 绘制渐变高光
for i in range(100):
    alpha = int(80 * (1 - i / 100))
    highlight_draw.ellipse(
        [margin + 60, margin + 40 + i, 
         size - margin - 60, margin + 120 + i],
        fill=(255, 255, 255, alpha)
    )

# 叠加到主图
img = Image.alpha_composite(img, highlight)
```

### 4. 发光边框实现

```python
# 创建发光层
glow = Image.new('RGBA', (size, size), (0, 0, 0, 0))
glow_draw = ImageDraw.Draw(glow)

# 多层边框叠加
for i in range(8):

        [i, i, size - i, size - i],
        radius=corner_radius - i // 2,
        outline=(255, 107, 107, alpha),
        width=2
    )

# 叠加到主图
result = Image.alpha_composite(result, glow)
```


```
- block: 宝石方块

- bg: 背景

- pressed: 按下状态
- hover: 悬停状态
- disabled: 禁用状态
```
