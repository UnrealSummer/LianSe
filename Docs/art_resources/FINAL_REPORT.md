## 经验总结

### 提示词技巧 📝

1. **参考具体资源** - "similar to OpenGameArt gem style"
2. **强调形状** - "hexagonal" 比 "rounded" 更精确
3. **明确风格** - "flat cartoon" 比 "glossy cartoon" 更接近
4. **简化描述** - 去掉过于复杂的效果

### 工作流程优化 ⚡

1. **先分析再生成** - 对比现有资源确定风格
2. **小批量迭代** - 生成1个验证后再批量
3. **及时缩放测试** - 1024x1024 ≠ 64x64效果
4. **保留原始文件** - 便于后续调整
